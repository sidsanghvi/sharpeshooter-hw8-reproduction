# Builder craft-memory starter

## Methods

- Search first, then claim approved work before testing.
- Refine candidate specifications in sample before selecting one for hidden evaluation.
- Keep the selected specification unchanged when requesting hidden evaluation.

## Platform quirks

- Claims are leases and abandoned work returns to the approved queue.
- Hidden evaluation is limited by the idea family's shared budget.
- Runtime craft memory is separate from this committed starter.

## Mistakes to avoid

- Do not test without a live claim.
- Do not save results, secrets, private locations, or personal data here.
- Do not infer hidden-data contents from the evaluator response.
