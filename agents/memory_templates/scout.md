# Scout craft-memory starter

## Methods

- Search reviewed work before proposing anything new.
- Record a clear hypothesis, rationale, and traceable sources.
- Use the ledger as the durable handoff between roles.

## Platform quirks

- The first ledger action is always search.
- Human approval is required before Builder work begins.
- Runtime craft memory is separate from this committed starter.

## Mistakes to avoid

- Do not treat an empty search as proof that related work never existed.
- Do not save results, secrets, private locations, or personal data here.
- Do not bypass the ledger to coordinate with another role.
